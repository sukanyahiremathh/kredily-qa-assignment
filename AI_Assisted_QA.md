# AI-Assisted QA

## Objective
Document how an AI tool was used to assist the Kredily HRMS QA assignment.

## Activity
Example activity: generating initial test-case ideas / improving Appium test structure.

## Prompt Used
"Generate positive, negative, and edge-case test scenarios for a mobile HRMS application covering login, dashboard, attendance, and leave."

## AI-Generated Output
The AI generated candidate scenarios such as valid/invalid login, blank fields, attendance check-in/check-out, duplicate check-in, valid leave submission, missing leave fields, and invalid date ranges.

## What I Changed / Validated
- Reviewed every AI-generated scenario against the actual application.
- Removed scenarios that were not applicable to the Kredily application.
- Added application-specific scenarios discovered during exploration.
- Executed the final test cases manually.
- Did not treat AI output as proof of a defect; defects were reported only after actual reproduction.
